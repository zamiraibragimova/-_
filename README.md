# INKVERSE

Готовый статический сайт-каталог комиксов.

## Возможности
- адаптивный тёмный дизайн;
- поиск;
- фильтры Marvel / DC / другие;
- подробное окно комикса;
- демонстрационный блок чтения/превью;
- GitHub Pages compatible.

## GitHub Pages
Загрузите содержимое этой папки в репозиторий, затем Settings → Pages → Deploy from a branch → main → /(root) → Save.
